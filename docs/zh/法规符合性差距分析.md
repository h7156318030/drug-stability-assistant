# 法规符合性差距分析（2026-10）

[English](../en/gap_analysis.md) | **中文**

本文件把程序功能与公开法规要求逐项对标，列出**已实现、部分实现、未实现**的条目，并按优先级给出改进建议。它是内部工程文件，**不是**法规符合性声明。

## 一、状态与优先级说明

| 符号 | 含义 |
|------|------|
| ✅ | 已实现，且有代码与测试依据 |
| ◐ | 部分实现（有计算或提示，但缺少流程、判据细节或记录） |
| ✗ | 未实现 |
| ⚠ 待核对 | 程序采用的判据或阈值尚未对照官方原文核实，不应直接引用 |

优先级：**P0**＝在任何受监管用途前必须完成；**P1**＝申报或正式使用前应完成；**P2**＝增强项。

## 十一、已在本轮修复的计算与程序缺陷（需向使用者说明）

以下缺陷在本轮测试中被发现并修复，**既有研究的输出可能因此改变**：

1. 有效期使用了预测限而非回归均值的置信限（偏保守）。已改为 Q1E 的置信限。
2. 上限类指标（如有关物质）的有效期被报告为 0。已修复判断方向。
3. 批合并判据为经验阈值，不是 Q1E 的显著性检验。已替换为 ANCOVA 逐级检验。
4. 数据录入、有效期推算、分析页及实时校验存在运行时异常。已修复。
5. 示例数据工具在空库上失败。已修复。
6. 研究管理页的删除、导入导出和添加样品区块只在点击教学示例按钮的那一次刷新中显示。已修复。

## 十二、建议的实施顺序

1. **P0 批次**：验证计划与需求追溯；修改原因与内容哈希；口令复杂度、有效期与会话超时；OOS/OOT 调查记录；方案审批门；中间条件触发规则；暗对照；稳定性指示方法与方法验证的关联；Q1E 外推规则与生物制品判据的原文核对。
2. **P1 批次**：双人复核；储存条件声明草稿；CTD 格式输出；容器封闭系统与 CCIT 数据模型；审计链外部锚定；备份加密。
3. **P2 批次**：稳定性承诺跟踪；原料药复验期输出；统计缩减设计的不确定性对比。

## 十三、需要法规原文核对的条目（汇总）

- ICH Q1A(R2) 中间条件触发规则与显著变化判据全文。
- ICH Q1E 外推规则（批数、覆盖比例、外推倍数）原文措辞。
- ICH Q5C 生物制品显著变化判据（效价 10%）原文。
- 《中国药典》2025 年版通则 9001 与《生物制品稳定性研究技术指导原则（试行）》原文。
- ICH Q1 合并草案的最终状态（是否已替代 Q1A–Q1E）。

> 本文件仅列出程序与法规要求之间的差距，不构成合规结论。实际申报前，应由具备资质的人员按上述条目逐条核对原文，并完成系统的计算机化验证。
