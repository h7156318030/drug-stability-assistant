# 使用手册

[English](../en/user_guide.md) | **中文**

> 本手册介绍日常操作流程。程序中的限度、时间点和阈值均为示例值，请以方案和现行法规为准（见 [法规依据](法规依据.md)）。

## 1. 安装与启动

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 `http://localhost:8501`。首次启动会自动创建管理员 `admin`：

- 若设置了环境变量 `STAB_ADMIN_PASSWORD`，口令即为该值；
- 否则控制台会输出一次性随机口令，请记录后登录。

> **注意**：早期版本（V2.3 及以前）使用固定默认口令 `Admin@2026`。若你的数据库是由旧版本创建的，请**立即**以该口令登录并修改口令。

## 1.1 界面语言

登录页或侧边栏顶部可切换中文 / English。切换只影响界面文字；研究名称、批号、检测项目等数据保持录入时的原文，报告与图表标题目前仍为中文。

## 2. 角色与权限

| 角色 | 可以做什么 |
|------|-----------|
| 管理员 admin | 全部功能，包括用户管理、审计日志、系统维护（备份/恢复） |
| 研究负责人 manager | 创建与删除研究、录入数据、分析、导出、查看审计日志 |
| 分析员 analyst | 创建研究、录入数据、分析、导出 |
| 只读访客 viewer | 查看数据、运行分析、导出报告 |

所有写操作（创建、修改、删除、导入、恢复、登录、改口令等）都会写入审计日志。审计日志只能追加，不能修改或删除。

**关键操作需重新输入口令（电子签名）**：删除研究、生成整库备份、整库恢复、创建用户、禁用或启用用户时，系统会要求再次输入您的登录口令。口令错误会计入登录失败次数，达到阈值会临时锁定账户；成功的操作会写入审计日志（`ESIGN`）。

## 3. 推荐工作流程

1. **研究管理**：新建研究，选择化学药或生物制品、设计类型（全检 / 括号法 / 矩阵法），可使用方案模板。
2. **添加样品**：录入批次、包装、条件。系统按 ICH 推荐条件自动生成取样时间点计划。
3. **数据录入**：按样品 × 条件 × 时间点录入检测值，或使用 CSV 批量导入。录入时会做范围与格式校验。
4. **分析与时序图**：查看各指标的回归斜率、年降解率、R² 与趋势图，检查限度线。
5. **有效期推算**：按 95% 置信限推算有效期；可查看多模型比较、Bootstrap 置信区间和留一法结果。
6. **质量告警**：检查离群值、缺失观测、显著变化等提示，逐一确认原因。
7. **导出报告**：导出 Excel 或 PDF，内含研究概览、计划、数据、分析与告警等内容。

## 5. 备份与恢复

- **应用内**：系统维护 → 导出备份（JSON，含用户口令哈希与审计日志）。恢复时保留审计日志与用户表。
- **命令行**：`python tools/backup.py backups/stability_YYYYMMDD.json`

备份文件含口令哈希与审计记录，请妥善保管，**不要**放入公开仓库。

## 6. 数据库

- 默认使用项目根目录下的 `stability.db`（SQLite）。可用 `STAB_DATA_DIR` 指定其他目录。
- 设置 `DATABASE_URL=postgresql://...` 可切换到 PostgreSQL（需要 `psycopg2-binary`）。**PostgreSQL 路径尚未完整实测。**

## 7. 示例数据

```bash
python tools/seed_example.py
```

会写入一个化药片剂示例和一个生物制品单抗示例（含非线性降解演示）。仅用于体验，**不要在正式数据库上运行**；如需隔离，先设置 `STAB_DATA_DIR`。

## 8. 常见问题

- **忘记管理员口令**：目前没有图形化重置功能。请在停止服务后，用备份恢复，或直接在数据库中替换 `users` 表中 `admin` 的口令哈希（需由具备权限的人员操作并记录）。
- **有效期显示“观测期内合格”或为空**：通常是数据点不足（回归需要足够时间点），或起点已超限度。请查看分析页的提示文字。
- **图表中文字体异常**：`src/fonts.py` 会尝试配置中文字体；如本机缺少中文字体，请安装后重启。
