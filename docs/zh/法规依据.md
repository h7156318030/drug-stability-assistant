# 法规依据与核对状态

[English](../en/regulatory_basis.md) | **中文**

本文件说明系统各功能依据的法规，并记录每项依据的**核对状态**。

> **使用原则**：下表“核对状态”一栏记录的是本项目在 2026-10 检索与整理时的结论。凡标注“未取得原文 / 待核对”的，**不得把程序中的判据直接当作法规要求引用**，须先取得官方原文逐条核对。

## 二、程序判据与依据的对应关系

| 程序功能 | 依据 | 说明 |
|----------|------|------|
| 取样时间点计划 | ICH Q1A(R2)；Q1D（括号/矩阵）；Q5C（生物制品） | 时间点为推荐值，实际计划应由方案确定 |
| 有效期推算 | ICH Q1E：95% 单侧置信限与回归 | 程序默认用回归直线（均值响应）的 95% 单侧置信下限推算（2026-10 修正，此前误用了预测限）；多模型选择、Bootstrap 与留一法为**分析增强**，并非 Q1E 原文要求 |
| 批间合并回归 | ICH Q1E 批间合并检验 | 合并前应先检验批间斜率与截距的差异 |
| 光稳定性判定 | ICH Q1B | 按总照度与近紫外能量两个阈值判断 |
| 生物制品显著变化（效价 > 10%） | 项目内设定，参考 ICH Q5C 讨论 | **待对照 Q5C 原文确认**；在核实之前，以方案定义为准 |
| 冻融 / 使用中 / 运输稳定性 | Q5C 与中国《生物制品稳定性研究技术指导原则（试行）》 | 具体条件与判据以方案和原文为准 |
| 强制降解确证 | 中国药典 9001（化学药）；Q5C（生物制品） | 检查是否具备稳定性指示能力，判据为程序内规则 |
| 数据完整性与电子签名 | 21 CFR Part 11；ALCOA+ | 仅为设计参考，未经验证 |

## 三、使用本系统时应注意

1. 程序中的限度、时间点、阈值为**示例或参考值**，须以所适用的法规原文和产品标准为准。
2. 有效期结论须由授权人员综合判定，系统输出仅供参考。
3. 依据未取得原文的条目，不得在申报或审评材料中作为法规要求引用。
4. 法规会更新。请在引用前确认版本与生效日期。
